# AtechOS

The Operating System for Schools.

AtechOS is a multi-tenant school-management platform for schools, administrators, teachers, students, parents and staff.

## Stack

- Next.js + React + TypeScript
- Supabase / PostgreSQL
- Vercel
- GitHub

## MVP roadmap

1. Authentication and school onboarding
2. Roles and permissions
3. Student, parent and teacher management
4. Classes and subjects
5. Attendance
6. Grades and assignments
7. Documents and reports
8. Payments, meetings and notifications
9. Quizzes, forum and kiosk integrations

## Local development

Install dependencies with `npm install`, copy `.env.example` to `.env.local`, add the Supabase project URL and publishable key, then run `npm run dev`.
